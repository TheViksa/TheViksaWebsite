# The Vixa

The Vixa is a modern business website designed for renting a vacation home. The platform offers an intuitive and seamless experience for users looking to book a getaway for various occasions.

## 🚀 Technologies Used

- **Next.js** – Fast, scalable, and SEO-friendly web application
- **Tailwind CSS** – Utility-first styling for a responsive and modern UI
- **Sanity CMS** – Headless CMS for dynamic content and offer management
- **Nodemailer** – Handles email submissions via the contact form
- **Zod** – Ensures secure and structured data validation
- **Radix UI** – Accessible and customizable UI components
- **React Hook Form** – Efficient form handling for improved user interactions
- **Framer Motion** – Smooth animations for enhanced user experience

The Vixa provides a professional and user-friendly interface for managing vacation rental bookings, ensuring an effortless experience for both owners and guests.
